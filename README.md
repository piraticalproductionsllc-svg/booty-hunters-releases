# Booty Hunters! Digital Releases

This public repository is the distribution endpoint for **Booty Hunters! Digital** platform packages published by Piratical Productions LLC.

The game’s canonical development source remains private. This repository contains only release/install artifacts intended for platform distribution, such as Foundry VTT manifests and downloadable packages.

## Access and subscriptions

Installing a platform client does not itself grant paid content. Booty Hunters! Digital is being built around a shared account and entitlement service so subscriptions and owned content can follow players across supported platforms where marketplace rules permit.

## Foundry VTT

Foundry release manifests and install packages published here are generated from the canonical Booty Hunters! Digital source and should not be edited independently.
